# ---------- OPCIONAL: Modo IA (clonación de voz con RVC) ----------
# IMPORTANTE: LA APP FUNCIONA SIEMPRE SIN ESTO (degrade a DSP).
# El modo IA es MULTIMOTOR con auto-detección en tiempo de ejecución:
#   * Motor PyTorch RVC  -> usa el paquete `rvc`/`rvc_python` (NVIDIA CUDA,
#                           AMD ROCm, Apple MPS). Requiere Python 3.10-3.12.
#   * Motor ONNX RVC     -> usa onnxruntime (CPU/DirectML/CUDA). Portátil,
#                           funciona hasta Python 3.14 por CPU y NO exige
#                           el stack PyTorch completo.
#   * Si ninguno está disponible, el modo IA degrada a DSP sin cortar audio.
#
# La vía MÍNIMA y portátil (recomendada para cualquier PC, sin GPU):
#   pip install rmvpe-onnx onnxruntime
#   (rmvpe-onnx da el estimador de pitch ONNX y trae onnxruntime de CPU)
#
# Alternativas por plataforma (en tu entorno aparte):
#   NVIDIA:   pip install torch --index-url https://download.pytorch.org/whl/cu121
#   AMD/Intel (Windows): pip install torch-directml
#   AMD (Linux): pip install torch --index-url https://download.pytorch.org/whl/rocm6.1
#   Apple Silicon: pip install torch    (usa MPS automáticamente)
#   + el paquete RVC:  pip install rvc  (o tts-with-rvc-onnx para ONNX)
#
# La integración real del/los motores vive en app/engine/rvc_adapter.py.
# Cada máquina puede inyectar su propio adaptador (adapter=...) sin tocar
